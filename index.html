Slipstream

A neon arena movement shooter built around how it feels to move: air strafing, auto-bunnyhop, dashes and slides — in a browser tab, solo or as a four-player squad.

  • Three.js
  • Vite
  • WebRTC
  • WebAudio
Play in the browser ↗ Source Details
  • Quake movement, not "force while a key is held". Projection-limited acceleration on the ground, air-strafe acceleration in the air, 100 ms of coyote time, 130 ms of jump buffering and jump-cut for short hops. Speed also drives the FOV, camera roll and wind layer, so moving fast reads as fast.
  • Four weapon archetypes and five arenas. Rifle, shotgun (shell-by-shell reload you can interrupt), rail and a rocket launcher whose splash knocks you around — rocket jumps included. Arenas are themed by event, so NEO STRIKE, FRONTIER and WHITEOUT swap the light, sky, palette and gun skins without touching the geometry.
  • Waves, bosses and a meta layer. A warden every fifth wave, three difficulty tiers, coin buffs that only apply to the next run, and a seven-day daily-reward streak. Up to four players co-op peer-to-peer over WebRTC with hosted waves and automatic host migration.

Pixel Playground

Eight tiny arcade games with no framework, no build step and no network calls after the page loads.

  • Snake, 2048, Breakout, Pong, Memory Match, Simon, Minesweeper and a reaction test — each on its own page, sharing one small toolkit for scores, sound and canvas.

Raw File Website

Upload a file, get a raw link you can copy, share, hotlink or embed — from static hosting that cannot run an upload server.

  • Uploads are committed straight into your own repo through the GitHub API, with a fine-grained token that never leaves the browser.
  • Big files are split into 10 MB pieces plus a manifest, and a GitHub Actions workflow reassembles them into a release asset with a true raw URL a few minutes later.
  • One retrying save queue prevents parallel uploads from tripping over the branch, stalled uploads can resume, and deleting an entry removes its pieces, manifest, index row and published asset. A zero-dependency Node server ships for unlimited sizes.
  • GitHub API
  • Actions
  • Vanilla JS
  • Node

SEUsign

An on-device signer for developer certificates: sideload, patch and install iOS apps without a computer.

  • Sign and install applications on device, browse AltStore source repositories, and inspect detailed information about apps and your certificates.
  • Configurable signing options for appearance and Files-app support, compatibility and Liquid Glass patches, and tweak injection through ElleKit — including .deb and .dylib files.
  • A rebranded fork of Feather by Samara, GPL-3.0, built in Xcode with a macOS Actions runner producing the .ipa. No tracking, no analytics.

ZombsClone.io

An open-source ZombsRoyale.io clone: a top-down battle royale in vanilla JavaScript and Canvas.

  • Solo against up to 100 bots offline, or online on an authoritative Node server — no player-hosted sessions, no rooms or codes, just auto-match into a lobby.
  • A 9000px map with 13 named points of interest, 30 enterable houses, 13 weapons across five rarity tiers, chests, crates and a storm whose edge is a pulsing energy wall.
  • Performance is part of the design: cached scenery gradients, throttled minimap, substepped bullets so fast rounds cannot tunnel through walls, and automatic quality scaling with a live fps meter. Local accounts keep stats and a body colour.

  • Canvas
  • Node

Nebula Strike

A polished neon arena shooter with a complete account system, leaderboards and wave-based combat.

ChessHub

Free chess with six rated bots, peer-to-peer games with a friend, and a chess.com-style game review — all static, with no account.

  • Six bots from 300 to 1850, tuned by search depth, evaluation noise and how often they blunder. The strongest looks three ply with quiescence.

02 — About

Static by default,
hand-built on purpose.

Most of what's here is a game, because games are the hardest way to learn how input feels, how a frame spends its budget, and how much polish a loading screen can hide.

I'm a solo developer who likes the constraints of the open web: no build step if I can avoid it, no backend if the browser will do, and no asset packs when a few lines of WebAudio or a shader can make the sound and the light myself.

The rest is tooling — the things I wanted to exist, like a way to get real raw file links out of GitHub Pages, or an on-device signer that doesn't phone home. All of it is public, and most of it fits on a static host.

Static first
If it can ship as files on GitHub Pages, it does. Six of the eight run with no server at all.
Local-first data
Accounts, wallets and records live in browser storage, hashed and scoped to the device. No dashboard, no analytics, nothing to leak.
Feel over features
Coyote time, jump buffering, projection-limited acceleration. The controls are the design, not the settings menu.
Made, not bought
Procedural audio, generated textures, canvas art. The only download is the code.

Usual toolbox JavaScript & Canvas · Three.js · WebAudio · WebRTC & MQTT · Swift & Xcode · GitHub Actions
