About this particular 404

A static host cannot invent a page for a URL that does not exist — but it can serve this one.

GitHub Pages answers any unknown path with this file, which is why the address bar still says whatever you asked for. Nothing about your visit was logged: there are no trackers here, and no server to write a line into.

If you followed a link from somewhere on this site and ended up here, that is a bug rather than a missing page. The repository's issues are the place for it.
