01

Where it stands

No URL, no demo, no repository link — the card is marked rather than linked.

The project exists and is being worked on. What does not exist is anything public to point at: no deployed page, no repository, no board to open. Publishing a placeholder URL or a "coming soon" screen dressed up as the real thing would only waste a click.

When the first public version is live, this page gets the same treatment as the others: what the chess side actually does, how it is built, and a Play button.

02

What happens here next

The usual project note, once there is something to describe.

The home page card stays marked Not public until the first deploy. After that it gains a live link, and this page is rewritten with a lede, a few sections on how the interesting parts work, and the build details — the same shape as every other note here.

Nothing is claimed in the meantime. There is no feature list, no engine, no rules and no online mode, because none of that has been published and checked.

03

Why list it at all

A record of what is being built, not only what is finished.

Everything else here is public, or about to be. An unpublished entry is the same honesty in reverse: a note that the work exists, without pretending there is something to play. It is filtered under Games, so removing it later is a one-line change.

If you came looking for a chess board, there is not one yet. The rest of the work is on the home page, and the project notes go further into each one.
