01

Signing on the phone

The point is that the whole loop — pick an app, sign it, install it — happens on the device you are holding.

SEUsign signs and installs applications using your own developer certificate, and does it on-device. It also browses AltStore source repositories, so an app repository can be added and used without a desktop, and it shows detailed information about the apps you have and the certificates you hold.

  • AltStore sources — point it at a source and install from it, the same distribution format AltStore uses.
  • Certificate view — what you are signing with, and when it expires, in the app rather than in a keychain menu.
  • No tracking, no analytics — nothing about your usage leaves the device.
02

What you can change while signing

Signing is also the moment to patch an app, so the options are about modifying it rather than just wrapping it.

Appearance
Adjust the app's look as part of the signing configuration.
Files app
Allow support for the Files app, so the app can be given documents.
Compatibility
Patch apps for compatibility, so an older build still runs where you need it.
Liquid Glass
Apply the Liquid Glass patch at signing time.
Tweaks
Tweak injection for advanced users through ElleKit, including .deb and .dylib files.

The rest of the app is deliberately plain: a clean UI, a short path from "I have an .ipa" to "it is installed".

03

Building it yourself

Xcode locally, or the release workflow on a macOS runner if you would rather not open Xcode at all.

The repository uses submodules, so clone it recursively before opening SEUsign.xcworkspace, then select the SEUsign scheme and build for your device.

git clone --recurse-submodules https://github.com/uxp70/SEUsign.git
open SEUsign.xcworkspace
# select the SEUsign scheme, build for your device

The GitHub Actions workflow at .github/workflows/release.yml builds on a macOS runner and produces packages/SEUsign.ipa. Trigger it from the Actions tab, or push a v* tag.

Translations live in SEUsign/Resources/Localizable.xcstrings; adding a language is done through Xcode's string catalogue interface.

04

Credits and licence

This is a fork, and the README is honest about what it stands on.

SEUsign is a rebranded fork of Feather by Samara (claration), released under the GPL-3.0. The signing pipeline leans on Zsign, device communication on idevice, packaging help came from ByePassHub's ecosystem, and the http server follows patterns from Asspp; LiveContainer, Nuke, Vapor, plistserver and backloop.dev are credited for fixes, caching, the server framework and a locally trusted certificate.

Sideloading with a developer certificate is a personal-use workflow, not an App Store install. You need your own certificate, and what you sign is your responsibility.
